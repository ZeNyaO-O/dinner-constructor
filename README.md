# 🍽️ Dinner Constructor
**Dinner Constructor** - Консольное приложение, написанное на Java для составления случайных комбинаций блюд.

----

## 🚀 Функциональность
- Добавление блюд по категориям.
- История генераций и подменю генерации обедов.
- Удаление отдельных блюд, категорий и очистка каталога с подтверждением.
- Переименование блюд внутри категории.
- Готовый каталог блюд.
- Проверка пустых названий и автоматическое удаление крайних пробелов при вводе.
- Поиск блюд по части названия.
- Подменю просмотра каталога: все блюда, блюда категории и статистика.
